# ADR-0001 Architecture decisions (first build)

1. **Kinematic server simulation, not Roblox physics, for scored objects.** The chicken, lawball, well, bot and drone are simulated in pure Luau (`LawSim`, `HeistSim`) at a fixed 30 Hz server tick and presented through anchored server parts. Why: no network-ownership exploit surface, so clients cannot move scored objects, and the rules can be tested headless. Players still get genuine misses, bank shots off walls and pylons, and drag. Trade-off: the cargo cannot tumble, and replication runs at the server tick (client smoothing is backlog). Revisit if Studio feel tests show stutter.
2. **SoloGauntlet topology (CR-002).** Each player owns one match keyed by the server-side `UserId`. Arenas sit `ARENA_SPACING` = 600 studs apart. Positions are converted to arena-local coordinates, so a player standing in someone else's arena is simply "too far" from their own objects. Shared multiplayer is deferred until two-client Studio tests exist.
3. **One intent remote, schema-validated.** Clients send intents only: an exact key set, finite bounded numbers, a monotonic sequence number and a token-bucket rate limit. Clients never send positions, score, ids, timestamps or prices.
4. **GoalWitness is the only scoring path (CR-001).** A score needs a dwell of 8 consecutive ticks plus a causal THROW or PLANT within the last 10 s. Steal alone does not count, and neither does recovery, which structurally cannot score. The witness mints one `scoredEventId` per round, and MatchCore keeps an exactly-once award ledger.
5. **ProximityPrompts for discoverable first actions.** STEAL, CUT POWER, REROUTE, OPEN ESCAPE and GRAB CORE use prompts. Each prompt is filtered to its owner and routed through the same validated intent path.
6. **Blinded A/B.** The outcome card's switch button reads "OTHER GAME" so the comparison does not lean on game names. Elastic Recovery is a flag (`Config.Flags.ElasticRecovery`) so on/off arms can be compared.
7. **Adaptive Reality is client-only.** It scales decor, particles and clouds, and is capped by the player's own Roblox graphics setting. Essential cues are server parts and look the same on every tier. A test asserts that no FX profile key overlaps a gameplay constant.
